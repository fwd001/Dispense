## 踩坑修复（重要教训，可复用）
推送后第一个 run **failure、jobs 为空** = workflow 无效。根因：**GitHub Actions 的 job 级 `if`
只能引用 `github/needs/vars/inputs`，引用 `secrets` 会让整个 workflow 判无效**。
修复：把 secrets 存在性 guard 移到 **Deploy step 的 `env` 求值 + `if: env.CONFIGURED == 'true'`**
（step 级 env/if 允许 secrets）。修正后 run success，步骤证据：
`Run tests → success`（每次 push 都跑 CI 回归）、`Deploy via SSH → skipped`（secrets 未配自动跳过）。
提交 a5d5bff 已推送，远端 Actions 绿灯。
